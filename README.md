## 1. 小陀螺为什么影响传统自瞄？

小陀螺运动会导致目标角速度变化，使传统预测模型无法准确预测目标位置。

主要原因：

- 目标运动具有非线性
- 角速度变化较大
- 图像容易产生运动模糊

## 3. 相机标定

相机由于镜头制造误差会产生畸变。

标定可以获得：

- 相机内参
- 畸变参数

提高测距和定位精度。
相机内参标定的作用是确定相机真实的成像参数，消除镜头误差，使像素坐标能够准确映射到三维空间。如果不标定，焦距、主点和畸变参数不准确，会导致目标尺寸计算、距离测量以及三维定位产生较大误差。
